About me

I'm an aspiring data engineer in Savannah, GA, with a B.S. in Information Technology (Data Analysis) from Georgia Southern University. I build pipelines that take messy data and make it trustworthy: ingestion, transformation, testing, and the SQL that serves it.

I started in web development, which taught me to think about the people who use what I build. Today my focus is data work: dbt and Snowflake models, PostgreSQL schemas, and Python ETL, with automated tests and honest documentation of what the data can and can't show.

I'm looking for entry-level data engineering and analytics engineering roles where I can build and maintain reliable data workflows.

Tech stack: Python (Pandas, SQLAlchemy), SQL, dbt, Snowflake, PostgreSQL, Streamlit, Git, GitHub Actions, Excel

Automated Logistics Risk

A dbt + Snowflake pipeline joining 99,441 Brazilian e-commerce orders with 10M+ historical weather records. Orders were 3.2x more likely to be late when severe weather hit the delivery destination (17.3% vs. 5.3%). Includes a Type 2 slowly changing dimension, automated data quality tests, and resumable ingestion that survived an undocumented API rate limit. Findings are reported with correlation-vs-causation caveats.

NFL Stats Pipeline

An ETL pipeline and Streamlit dashboard for NFL QB and WR performance, 2015-2025. Joins weekly stats to real snap counts through an ID crosswalk, loads a star-schema PostgreSQL database (Supabase), and serves 12 SQL leaderboard views. Custom metrics include snap efficiency and a consistency score based on week-to-week variation. Includes unit tests and CI.
